# 🔐 Simple Cryptography App (AES-256 CBC)

Aplikasi Python sederhana untuk melakukan **enkripsi dan dekripsi teks menggunakan algoritma AES-256 dengan mode CBC (Cipher Block Chaining)**.

Project ini dibuat sebagai mini project mata kuliah **Keamanan Data** untuk menunjukkan proses perubahan data dari **plaintext → ciphertext → plaintext** menggunakan kriptografi simetris.

---

## 🚀 Fitur

- Enkripsi teks menggunakan **AES-256 CBC**
- Dekripsi ciphertext kembali menjadi plaintext
- Pembuatan **random key (256-bit)** otomatis
- Menggunakan **Initialization Vector (IV)** acak
- Output ciphertext dalam format **Base64**
